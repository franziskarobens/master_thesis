\begin{definition}[Type-I Censored Data] \label{def:type_1}
	Let $X_1, \dots, X_n$ be random variables with CDF $F_X$, and let $C > 0$ be a fixed, deterministic censoring time. Define the observed random variables as
	\[
	Y_i = \min(X_i, C), \quad i = 1, \dots, n.
	\]
	The data $Y_1, \ldots, Y_n$ is called \textbf{Type-I censored data} with censoring time $C$. An observation is called \textbf{uncensored} if $X_i \leq C$ (equivalently $Y_i = X_i$), and \textbf{censored} if $X_i > C$ and the exact value of $X_i$ remains unknown.
	The cumulative distribution function of $Y_i$ is given by
	\[
	F_Y(t) =
	\begin{cases}
		F_X(t), & t \leq C, \\[2pt]
		1, & t > C.
	\end{cases}
	\]
\end{definition}


The censoring indicators
\[
\delta_i = \mathds{1}_{\{X_i \le C\}}, \qquad i = 1, \dots, n.
\]

The number of uncensored observations
\[
N = \sum_{i=1}^{n} \mathds{1} (X_i \leq C) = \sum_{i=1}^n \mathds{1} _{(- \infty, C])} (X_i)
\]
is random, since it depends on the realizations of $X_1, \dots, X_n$, whereas the censoring time $C$ is fixed in advance. This is what distinguishes Type-I censoring from Type-II censoring, where instead the number of observed failures is fixed and the censoring time is random.


\begin{definition}[Type-II Censored Data] \label{def:type_2}
	Let $X_1, \dots, X_n$ be random variables with CDF $F_X$, and let $m \in \{1, \dots, n\}$ be a fixed number of observed failures. Let
	\[
	X_{1:n} \leq X_{2:n} \leq \cdots \leq X_{n:n}
	\]
	denote the ordered observations. The data are called \textbf{Type-II censored data} if observation stops when the $m$-th failure occurs, that is, at the random censoring time
	\[
	C = X_{m:n}.
	\]
	
	The first $m$ observations
	\[
	X_{1:n}, \dots, X_{m:n}
	\]
	are observed exactly and are therefore uncensored. The remaining observations
	\[
	X_{(m+1):n}, \dots, X_{n:n}
	\]
	are censored, since their exact values are unknown and only the information
	\[
	X_i > X_{m:n}
	\]
	is available.
\end{definition}

Thus, the number of uncensored observations is fixed and equal to $m$, while the censoring time $X_{m:n}$ is random. This distinguishes Type-II censoring from Type-I censoring, where the censoring time is fixed and the number of uncensored observations is random.




\textcolor{red}{($\star$) problem erklären}

There are some limitations of Type-I and Type-II censored data schemes.
Type-I censored data guarantees a fixed duration of an experiment, but failes to guarantee a minimum number of observations since all observations could be larger than $C$. In this case $N = 0$. Or $N$ could be very small which results in unstable inference. 

On the other side type-II censored data guarantees a fixed number of observations $m$, but does not restrict the duration of the experiment.

The following censoring schemes from Definition~\ref{def:type_1_hybrid} and~\ref{def:type_2_hybrid} combine the classic type-I and type-II censoring schemes from Definitions~\ref{def:type_1} and~\ref{def:type_2}.

\begin{definition}[Type-I-hybrid Censored Data] \label{def:type_1_hybrid}
	Let $X_1, \ldots , X_n$ be random variables and let $m \in \{1, \dots, n\}$ and $C > 0$ be fixed.
	The experiment is stopped after \textbf{one} of the conditions is fulfilled:
	\begin{enumerate}
		\item $X_{m:n}$ is observed
		\item $C$ is reached
	\end{enumerate}
\end{definition} 

This means that the test duration is given by
\[
	\min \left( X_{m:n}, C \right)
\]
and the number of observations by
\[
	\min \left( m, d_C \right)
\]
whereas $d_C = \sum_{i=1}^n (X_i \leq C)$.

\begin{definition}[Type-II-hybrid Censored Data] \label{def:type_2_hybrid}
	Let $X_1, \ldots , X_n$ be random variables and let $m \in \{1, \dots, n\}$ and $C > 0$ be fixed.
	The experiment is stopped when \textbf{both} of the following conditions are fulfilled:
	\begin{enumerate}
		\item $X_{m:n}$ is observed
		\item $C$ is reached
	\end{enumerate}
\end{definition}


This means that the test duration is given by
\[
\max \left( X_{m:n}, \min \left( C, X_{n:n} \right) \right)
\]
and the number of observations by
\[
\max \left( m, d_C \right)
\]
whereas $d_C = \sum_{i=1}^n (X_i \leq C)$.

Again we have the problem, that for type-I censored data, there is no guaranteed minimum number of observations. In contrast to normal type-I censoring, hybrid-type-I censoring only ensures a maximal duration of the test instead of a fixed one. The experiment ends earlier than $C$, if there are $m$ observations with $X_i < C$.

For hybrid-type-II censoring, there is a guaranteed minimum number of observations but no maximal test duration. In contrast to type-II censoring. hybrid-type-II censoring ensures than minimum $m$ observations occur instead of a fixed number of obervations.
